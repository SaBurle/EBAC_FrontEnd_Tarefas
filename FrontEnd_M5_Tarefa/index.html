Guia de comandos Git

Passo a passo do fluxo de trabalho com Git e GitHub.

  1. Configuração inicial (apenas uma vez por máquina)
    1. Configure seu nome e e-mail. 
      git config --global user.name "SaBurle"
      git config --global user.email "seu.email@email.com"
  2. Clonando ou iniciando um repositório
    1. Clonar um repositório remoto existente. 
      git clone https://github.com/usuario/repositorio.git
      cd repositorio
    2. Se ainda não existe um repositório remoto: 
      mkdir meu-projeto
      cd meu-projeto
      git init
      git remote add origin https://github.com/usuario/meu-projeto.git
  3. Criando ou alternando para uma branch
    1. Crie uma nova branch para as suas implementações (boa prática). 
      git checkout -b minha-branch
    2. Ou alterne para uma branch que já existe. 
      git checkout main
  4. Fazendo modificações no código
    1. Realize as implementações necessárias no projeto.
  5. Adicione as alterações ao "stage" e faça um commit

    O "stage" é uma área temporária onde você prepara as alterações antes de fazer o commit.

    1. Para adicionar um arquivo específico: 
      git add nome-do-arquivo
    2. Para adicionar todos os arquivos modificados: 
      git add .
    3. Crie um commit para registrar suas mudanças. 
      git commit -m "mensagem do commit"
  6. Enviando alterações para o repositório remoto
    1. Certifique-se de que está na branch correta. 
      git branch
    2. Envie suas alterações para o repositório remoto. 
      git push origin minha-branch
  7. Sincronizando alterações
    1. Atualize sua branch local com as mudanças remotas. 
      git merge
    2. Resolva os conflitos, se houver.
      • Edite os arquivos conflitantes.
      • Após resolver os conflitos, adicione os arquivos corrigidos. 
        git add nome-do-arquivo
        git commit -m "resolvendo conflitos"
  8. Determine o tipo de repositório
    1. Se for um repositório colaborativo (envolvendo outras pessoas):
      • Abra um pull request (PR) ou merge request (MR) na plataforma do repositório remoto (GitHub, GitLab etc.) para revisão e aprovação.
    2. Se for um repositório pessoal (trabalho individual):
      • Faça o merge diretamente na branch principal. 
        git checkout main
        git merge minha-branch
        git push origin main
  9. Publicando a página online com GitHub Pages (opcional)

    O GitHub Pages transforma o repositório em um site, com um link público.

    1. No repositório, abra Settings e depois Pages.
    2. Em Source, escolha Deploy from a branch.
    3. Em Branch, selecione main e a pasta / (root). Depois clique em Save.
    4. Aguarde de 1 a 2 minutos. O link aparece no topo da página Pages, neste formato: https://usuario.github.io/repositorio/
